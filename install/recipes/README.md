# Install recipes

One YAML per app, mirroring `control/registry/apps/` ids. Phase 0 files are skeletons
generated by `tools/gen-registry-stubs.py`; `PIN-ME` markers mark fields the kit
builder must pin (URL + SHA-256) at Phase 3.

Strategies (spec §8): `dnf`, `dnf-verify` (audit decides dnf vs build), `build`,
`tarball`, `wine` (user-supplied installer), `pip-vendored`, `static`.

Rules:
- VARA-family recipes reference `kit-import/` artifacts and **never** embed download URLs (G6).
- Every pinned artifact records `sha256`; the builder writes them into the kit manifest.
- Recipe strategy must match the registry entry's `install.strategy` (enforced by tests).
